# hstun: agent notes

Go module `hstun`.

- Toolchain: Go >= 1.26.11 via mise (`mise install go@1.26`; scripts find it with `mise where go@1.26`). Go 1.25.x has 11 stdlib CVEs in net/http, crypto/tls and crypto/x509 that govulncheck reports as reachable; never ship a build from it. Build once and copy the static binary to the hosts.
- Build: `scripts/build.sh`. Test: `scripts/test.sh` (add `-short` to skip the ~100 s of slow tests). Run both before committing.
- No secrets in git: `.gitignore` blocks `secret`, `*.key`, `*.pem` and every `*.toml` except `*.example.toml`. Keys are generated on the host with `hstun keygen` and never printed.
- Two modes: reverse (server=entry, client=exit) and direct (client=entry, server=exit). Check which one a host runs before touching it; see docs/modes-and-carriers.md.
- Security: everything after the handshake goes through `internal/seal`; never bypass it. New listeners must be loopback by default; new pre-auth input needs caps and a test.
- Stealth is a goal (2026-11-14: the operator lifted the earlier "plain TLS only" line). Browser-like ClientHello through uTLS (`internal/carrier/fingerprint.go`, `tls_fingerprint`, default `chrome`), padding, traffic shaping and other anti-DPI techniques are allowed; the plan lives in `docs/stealth-plan.md`. Rules that stay: verification is never turned off, everything after the handshake goes through `internal/seal`, and every new technique ships with a test that checks it on the wire or in a capture, plus a benchmark entry so it earns its cost. BackPack and C-Tunnel are AGPL-3.0 like hstun, so their code may be reused if their copyright notices and licence stay with it (check that each file is AGPL-3.0 or compatible, and note it in `THIRD_PARTY_NOTICES.md`); ideas need nothing. Never copy code from a project with an incompatible licence.
- Every new read/write/handshake needs a deadline and a length cap; add a wedge-style test for anything that accepts input from the network.
- Release checklist: when the uTLS snapshot changes, update the User-Agent majors in `internal/carrier/fingerprint.go` (`userAgents`) to the profile's browser version (`DefaultUserAgent` in `tlsconf.go` is only for `tls_fingerprint = "go"`), re-run the hello tests, run `scripts/test.sh`.
- The `chunk` carrier (one connection per request, each under a byte budget) is an explicit, operator-requested option for paths that cut long connections. It uses standard TLS and HTTP with one fixed SNI; random URLs, hosts or SNI rotation are possible additions but only if the benchmark in `docs/stealth-plan.md` shows a gain.
- Installer and releases: `install.sh` (installed on hosts as `hstun-ctl`) is the one-line installer and manager; keep `INSTALLER_VERSION` equal to `var version` in `cmd/hstun/main.go`. After changing it run `shellcheck -S warning install.sh scripts/*.sh` and `scripts/package.sh && scripts/test-install.sh`. Release: bump the version, `scripts/package.sh`, then `gh release create vX.Y.Z dist/hstun_*.tar.gz dist/SHA256SUMS --repo OWNER/hstun`; the installer downloads and verifies it. Go dependencies are vendored (`go mod vendor` after changing go.mod).
- Adopting hand-installed units: `hstun-ctl adopt` (see docs/operations.md; test: `scripts/test-adopt.sh`). Adopted instances carry `ADOPTED=1`, `ADOPT_UNITS`, `ADOPT_BIN` in `install.conf`; `install.sh exit|entry` refuses to touch them or any unmanaged `/etc/hstun[-NAME]`. Adopt writes only `install.conf`. Run `adopt --dry-run` before the real thing on a live host.
- License: AGPL-3.0-or-later (`LICENSE`), third-party notices in `THIRD_PARTY_NOTICES.md`; when go.mod changes, update that table and the licenses copied in `scripts/package.sh`.
- hstun-ctl commands (v0.3.x): `test`, `doctor`, `edit` (auto-undo), `backup`/`restore`, `rollback`, update with automatic rollback, contextual menu; tests: `scripts/test-install.sh`, `scripts/test-adopt.sh`, `scripts/test-ctl.sh` (all staging, no root). Re-running an install on an existing instance asks keep/change/reinstall and keeps the certificate, secret and paths.
- The server reloads its TLS certificate files when their modification time changes (`internal/server/certreload.go`); `/stats` shows `uptime_seconds` and `cert_not_after`.
- First stealth batch (T2-T11 in `docs/stealth-plan.md`, same release): negotiated padding frames (`internal/seal` pad frames, `mux.Announce`/`Refuse`, `KindCaps` stream; an older peer refuses the stream and gets no padding), jittered keepalive (`mux.keepalive`), `session_age` rotation with a draining session (`client.session`, `entry.Session.Draining`), `tls_fragment` (`internal/carrier/fragment.go`), cookie metadata for the http carrier (`httpmode/meta.go`, names from the secret path, both styles accepted), browser headers (`carrier.WithBrowserHeaders`), decoy-style error pages (`decoy.Error`), soak-based `auto` (`autoSoak`), chunk tuning between sessions (`carrier/tuning.go`), probe streams (`KindProbe`, `exit.serveProbe`), `hstun probe` and `hstun-ctl test --matrix`. Interop with an older release: `HSTUN_OLD=/path/to/old/hstun scripts/test-compat.sh` (build the old one from the commit of that release); run it after any wire change.
- v0.5.0: stream reset signalling (patched yamux in `third_party/yamux`, `Stream.Reset`, `netx.Abort`/`IsAbort`, session death resets streams), per-key limits (`max_mbit_per_key`, `max_new_streams_per_sec_per_key`, `internal/netx/limit.go`, `internal/server` `limitsFor`), graceful drain (`drain_timeout`, `Server.shutdown`, `Client.drainStreams`, second signal stops at once), installer flags `--max-mbit --max-new-streams --drain-timeout`, `--carrier auto` accepted by the installer. Tests: `internal/mux/pipe_reset_test.go`, `internal/e2e/limits_drain_test.go`, `internal/netx/limit_test.go`.
- v0.4.0: `carrier = "auto"` (ws -> http -> chunk failover with probe-back; `internal/client/picker.go`), dual-stack IPv6 listen (`--ipv6`/`--no-ipv6`, per-/64 caps in the firewall and Go limiter), `hstun-ctl rotate-secret` (exit adds `secret.new` next to the secret, entries follow, `--finish`), `hstun-ctl pin`. Tests in `internal/e2e` (TestAuto*, TestTunnelOverIPv6, TestDualStackListener) and `scripts/test-ctl.sh`.
